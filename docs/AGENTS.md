# 문서 작업 지도

## 문서 역할

- 루트 `README.md` 프로젝트 소개와 현재 구현 범위 및 실행 진입점
- `README.md` 문서 지도
- `계획.md` 두 개발 흐름과 완료 기준
- `구현현황.md` 코드에 구현한 것과 검증 근거
- `남은작업.md` 현재 미완료 작업의 기준 목록
- `design/` 현재 구조와 제품 계약
- `analysis/` 조사 결과와 구현 갭
- `plans/` 개별 변경 당시의 실행 계획과 작성 기준

## 읽는 순서

먼저 [README.md](README.md)의 계획 → 구현 현황 → 남은 작업 순서로 읽는다
현재 자동 처리 기준은 [design/자동처리.md](design/자동처리.md)와 [실행 모듈 계약](../CONTRACTS.md)
영상 분석 근거는 [analysis/영상조사.md](analysis/영상조사.md)와 [design/영상설계.md](design/영상설계.md)
전체 링크는 [README.md](README.md)에 있다

## 작성 제약

- AGENTS.md에는 지도와 링크만 추가하고 긴 설명은 해당 문서에 기록한다
- 조사 사실과 검증 전 제안을 구분한다
- 현재 코드와 맞지 않는 과거 계획은 완료된 설계처럼 쓰지 않는다
- 새 구현은 구현현황과 남은작업을 함께 갱신하고 배포·실영상 승인과 구분한다
- 오래된 계획의 미체크 항목을 현재 할 일로 그대로 가져오지 않는다
- 이 디렉터리는 로컬 문서로 gitignore 대상이므로 저장소 변경과 혼동하지 않는다
