# 인식 실증 작업 지도

이 영역은 2026년 9월 10일 사용자가 개발 우선 진행을 승인한 RT-DETR-R18 검출과 ByteTrack 추적의 독립 실증이다

- `src/replay_perception/` 원본 시간축과 모델 검출 및 추적과 진단 출력
- `tests/` 합성 입력과 실제 디코더 및 선택적 모델 검증
- `requirements.txt` 운영 Worker와 분리한 실행 의존성
- `README.md` 설치와 실행 및 확인한 한계

기존 검출은 지정한 공개 RT-DETR 가중치만 허용한다
별도 승인된 심판 관측 경로에서는 martinjolif/yolo-football-player-detection과 usyd-community/vitpose-plus-small의 고정 가중치만 추가로 허용한다
생성형 모델과 외부 추론 API 및 추가 학습은 사용하지 않는다
원본 영상과 모델 가중치 및 출력은 저장소 밖에 둔다
모델과 설정 파일은 고정 revision 및 SHA256을 확인한 뒤 로컬에서 읽는다
기존 사람 검출의 UNPROVEN은 유지하고 새 역할 가설과 자세 관측을 독립 기록에 둔다
물체 접근과 팔 동작을 접촉과 파울 및 선언된 판정으로 변환하지 않는다
원본 PTS와 좌표 변환 및 추론 설정과 실패 상태를 남긴다
운영 연동 산출물은 [운영판정연결](../../docs/design/운영판정연결.md)의 승인 경계만 사용한다. DB와 웹 변경은 해당 영역 지침을 따른다
다른 작업자의 파일과 기존 미커밋 변경을 되돌리지 않으며 커밋하지 않는다

설계는 [인식모델](../../docs/design/인식모델.md), 계획은 [인식실증계획](../../docs/plans/인식실증계획.md)을 따른다
후속 관측은 [심판관측](../../docs/design/심판관측.md)과 [심판관측계획](../../docs/plans/심판관측계획.md)을 따른다
